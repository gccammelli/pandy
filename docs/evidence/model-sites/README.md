# Thingiverse and Printables

Android (OnePlus A3003, debug build, demo printer), 28 October 2026.

- `long-press-menu.png`: long-pressing the Models tab (or Me's MakerWorld shortcut) offers MakerWorld, Thingiverse and Printables.
- `thingiverse.png`: Thingiverse in the Models tab.
- `printables-stl-print-sheet.png`: the real Printables 3D Benchy STL (11 MB), wrapped into a 3MF, on the print sheet.

Not covered here: an actual print on a printer (no printer was started). Pandy Slicer sliced the wrapped Benchy 3MFs from both
sites on a local server (about 83 minutes, start sequence verified); the printer upload and start were not run.
